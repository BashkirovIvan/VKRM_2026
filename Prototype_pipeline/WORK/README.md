# Пайплайн анализа механоплетизмографических сигналов

Данный пайплайн предназначен для автоматизированной обработки многоканальных биомедицинских сигналов, записанных носимым механоплетизмографическим комплексом, с целью расчёта:

- скорости распространения пульсовой волны (СРПВ);
- вариабельности сердечного ритма (ВСР);
- артериального давления (АД).

Пайплайн реализован на Python и ориентирован на выполнение в среде Google Colab (с возможностью локального запуска после корректировки путей).

---

## Основные возможности

- Загрузка и предобработка сигналов ЭКГ и механоплетизмограмм из CSV-файлов.
- Автоматическое маскирование дыхательных и двигательных артефактов.
- Детекция R-пиков ЭКГ методом оператора энергии Тейгера–Кайзера (TKEO).
- Определение характерных точек (foot-точек) плетизмограмм и расчёт PTT / СРПВ.
- Вычисление метрик ВСР (SDNN, RMSSD, pNN50).
- Автоматическая оценка качества каждой записи по трём критериям.
- Пакетная обработка всех записей пациентов с формированием сводных таблиц.
- Оценка PTT с помощью обученной одномерной свёрточной нейронной сети (1D CNN).
- Индивидуальная настройка и оценка артериального давления по значениям СРПВ.

---

## Структура и взаимодействие модулей

Пайплайн состоит из четырёх модулей (подробнее — в [MODULES.md](MODULES.md)):

| Модуль | Назначение |
|--------|------------|
| `pwv_single.py` | Обработка одного CSV-файла (фильтрация, детекция, расчёт PTT/СРПВ/HRV) |
| `batch_pwv.py` | Пакетная обработка всех пациентов, сводные таблицы и дашборд |
| `pwv_cnn.py` | 1D CNN для оценки PTT, обучение и инференс |
| `pwv_bp_calibration.py` | Калибровка «СРПВ – АД» и оценка давления без манжеты |

Модуль `pwv_single.py` является базовым и импортируется остальными тремя.

## Входные данные

### CSV-файлы записей
- Формат: CSV без заголовка.
- Порядок столбцов: `счётчик, плетизмограмма груди, плетизмограмма запястья, вспомогательный канал, ЭКГ`.
- Частота дискретизации: **488,28 Гц** (задаётся константой `FS` в `pwv_single.py`).

### Файл конфигурации `config.json`
Для каждого пациента указываются:
- идентификатор;
- расстояние между датчиками (м);
- коэффициент порога TKEO;
- верхняя частота среза фильтра плетизмограммы (Гц);
- список имён CSV-файлов.

Пример:
```json
{
  "patients": [
    {
      "id": "P01",
      "distance_m": 0.5,
      "tkeo_threshold": 1.2,
      "lp_cutoff_hz": 30.0,
      "files": ["P01_rec1.csv", "P01_rec2.csv"]
    }
  ]
}
```

### Для настройки АД
Значения СРПВ (м/с) и соответствующие манжетные измерения систолического/диастолического давления (мм рт.ст.) вводятся непосредственно в ячейку.

### Для инференса CNN
Файл обученной модели pwv_cnn_v2.h5.

## Выходные данные

| Файл | Описание |
|--------|------------|
| `results_per_signal.csv` | Результаты обработки каждого CSV-файла (PTT, СРПВ, HRV, доля артефактов, качество) |
| `results_per_patient.csv` | Агрегированные показатели по пациентам |
| `features_matrix.csv` | Расширенная матрица признаков (более 20 столбцов), включая флаг качества 'quality_ok' |
| `features_quality_ok.csv` | Записи, прошедшие фильтр качества |
| `pwv_cnn_v2.h5` | Сохранённая модель нейронной сети |

Также формируются интерактивные графики:
- обработка одного сигнала;
- дашборд сравнения пациентов;
- сравнение алгоритмического и CNN-инференса;
- кривые настройки АД.

## Запуск

По умолчанию, пайплайн делался под Google Colab:
- Загрузите все файлы модулей и config.json в папку на Google Drive;
- Подключите Drive;
- Добавьте путь к модулям;
- Выполните ячейки в нужном порядке (см. основной notebook или документацию);
- Для инференса без повторного обучения загрузите модель: 'pwv_cnn_v2.h5'.

Если запускать локально, то необходимо скорректировать пути к файлам и, возможно, заменить механизм importlib на обычный импорт. Кроме того, нужно проверить соответствие требованиям:

1) Python 3.9 или выше (рекомендуется 3.11);

2) Библиотеки:
 - 'numpy >= 1.21';
 - 'pandas >= 1.3';
 - 'scipy >= 1.7';
 - 'plotly >= 5.0';
 - 'scikit-learn >= 0.24';
 - 'tensorflow >= 2.8';
 - 'pathlib', 'json', 'argparse'.

Для локального запуска создайте requirements.txt с перечисленными версиями.

### Ограничения
- Обрабатываются только CSV без заголовка с фиксированным порядком столбцов.
- Частота дискретизации фиксирована (488,28 Гц) — при изменении аппаратной части требуется корректировка 'FS'.
- Расстояние между датчиками и порог TKEO задаются вручную в 'config.json'.
- Калибровка АД — только для одного пациента за раз, минимум 3 парных измерения (рекомендуется от 5).
- Нейросеть требует не менее 200 размеченных примеров для устойчивого обучения.
- Ориентация на Google Colab; при локальном запуске нужна адаптация путей.

Подробное описание модулей - см.  MODULES.md
