### Прошивка микроконтроллера MSP430 (`MSP430_code/`)

**Файл:** `main_v5_diploma.c`

Программа для микроконтроллера MSP430i2040, отвечающая за синхронный сбор аналоговых данных с четырёх каналов встроенного сигма-дельта АЦП (SD24), цифровую фильтрацию методом скользящего усреднения и передачу результатов на ПК по интерфейсу UART.

#### Основные функции
- Групповая синхронизация четырёх каналов АЦП (1 ведущий + 3 ведомых) для одновременной выборки сигналов.
- Скользящее усреднение каждого канала по 16 выборкам (частота дискретизации ~7812 Гц → выходная частота ~488 Гц на канал).
- Передача данных в виде 5-байтовых пакетов через UART (115200 бит/с, 8N1).
- Использование кольцевого буфера для согласования скоростей АЦП и UART.
- Энергосберегающий режим LPM0 (останов CPU при активной периферии).

#### Каналы данных
| Канал | Источник сигнала | Тип входа |
|-------|------------------|-----------|
| 0     | Датчик Холла 1   | дифференциальный, биполярный |
| 1     | Датчик Холла 2   | дифференциальный, биполярный |
| 2     | Датчик Холла 3   | дифференциальный, биполярный |
| 3     | ЭКГ (после усилителя) | однополярный, дифференциальный |

#### Формат пакета (5 байт)
| Байт | Назначение |
|------|------------|
| 0    | Синхробайт (0xA0 – Холл 1, 0xA1 – Холл 2, 0xA2 – Холл 3, 0xA3 – ЭКГ) |
| 1    | Старший байт усреднённого 24-битного значения (биты 23:16) |
| 2    | Средний байт (биты 15:8) |
| 3    | Младший байт (биты 7:0) |
| 4    | Контрольная сумма XOR байтов 1–3 |

#### Требования и ограничения
- Работает только с MSP430i2040.
- Передача только по UART на фиксированной скорости 115200 бит/с.
- Коэффициент усреднения фиксирован (16 выборок).
- Для загрузки прошивки требуется Code Composer Studio (v12.8.1+) и программатор MSP-FET (или LaunchPad с интерфейсом Spy-Bi-Wire).
