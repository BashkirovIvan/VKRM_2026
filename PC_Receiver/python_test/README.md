### Приёмник данных на ПК (`PC_Receiver/python_test/`)

**Файл:** `Project_ECG_v2_csv.ipynb`

Интерактивный Jupyter Notebook для приёма, декодирования и визуализации в реальном времени многоканальных данных, поступающих от микроконтроллера MSP430 через последовательный порт (USB-UART). Программа также сохраняет принятые данные в CSV для последующей обработки.

#### Основные функции
- Автоматическое обнаружение доступных COM-портов.
- Чтение и декодирование 5-байтовых пакетов данных с проверкой синхробайта и контрольной суммы (XOR).
- Отображение четырёх каналов (3 датчика Холла + ЭКГ) в виде динамических графиков (Plotly).
- Сохранение полученных данных в CSV-файл (`data1.csv`) с заголовками столбцов.
- Возможность работы в демонстрационном режиме с тестовыми данными (без подключённого устройства).

#### Формат входных пакетов
| Байт | Назначение |
|------|------------|
| 0    | Синхробайт: 0xA0 – Холл 1, 0xA1 – Холл 2, 0xA2 – Холл 3, 0xA3 – ЭКГ |
| 1–3  | 24-битное значение отсчёта (старший, средний, младший байты) |
| 4    | Контрольная сумма XOR байтов 1–3 |

#### Требования
- Python 3.7 или выше (рекомендуется 3.8 для совместимости с проектом).
- Jupyter Notebook (JupyterLab, классический Jupyter или VS Code).
- Библиотеки: `pyserial`, `numpy`, `plotly`, `pandas`, `ipywidgets`.
- Драйвер USB-UART (например, FT232R) для работы с COM-портом.

#### Ограничения
- Поддерживаются только 4 канала и фиксированный протокол пакетов.
- Параметры порта (скорость, биты данных) задаются вручную в коде (115200, 8N1).
- Интерфейс настройки отсутствует — требуется редактирование кода.
- Ориентирована на Windows, но может работать в других ОС при наличии драйверов.
