## О проекте

Данный репозиторий содержит программно-аппаратную реализацию носимого механоплетизмографического комплекса с магнитными датчиками для оценки состояния сердечно-сосудистой системы.

Комплекс предназначен для мониторинга параметров пульсовой волны и сердечного ритма в исследовательских задачах. В отличие от классических методов (ЭКГ, фотоплетизмография), используется метод механоплетизмографии с магнитными датчиками, что позволяет оценивать скорость распространения пульсовой волны и другие показатели.

Система включает:
- **Аппаратную часть** — электронный блок и набор датчиков (три магнитных датчика, опционально электроды ЭКГ);
- **Программное обеспечение** — прошивку микроконтроллера MSP430, программу приёма данных на ПК и алгоритмический пайплайн обработки сигналов.

Проект разработан в рамках дипломной работы и прошёл апробацию на трёх пациентах с различными клиническими профилями.

- **Прошивка для микроконтроллера MSP430** (`MSP430_code/`)  
  Отвечает за сбор первичных данных с датчиков и их передачу на ПК по USB-UART. Подробное описание прошивки: [MSP430_code/README.md](MSP430_code/README.md)

- **Приёмник на ПК** (`PC_Receiver/python_test/`)  
  Принимает данные от микроконтроллера, сохраняет их в формате .csv и подготавливает для дальнейшей обработки.

- **Пайплайн обработки** (`Prototype_pipeline/WORK/`)  
  Выполняет  над полученными данными.
