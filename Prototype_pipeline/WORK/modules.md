Данный документ содержит подробное описание четырёх Python-модулей, входящих в состав пайплайна анализа механоплетизмографических сигналов. Общие сведения, запуск и ограничения — в [README.md](README.md).

## 1. pwv_single.py

**Назначение:** обработка одной CSV-записи. Включает загрузку, фильтрацию, маскирование артефактов, детекцию R-пиков, поиск foot-точек, расчёт PTT/СРПВ и HRV.

### Основные функции

| Функция | Описание |
|---------|----------|
| `fix_zeros()` | Устранение нулевых отсчётов линейной интерполяцией |
| `mask_artifacts()` | Робастное маскирование артефактов (MAD-нормированный порог, морфологическое расширение) |
| `preprocess_esg()` | Полосовая фильтрация и z-нормировка ЭКГ |
| `detect_rpeaks()` | Детекция R-пиков методом TKEO с робастным порогом и автоматическим определением полярности |
| `detect_feet_chest()` / `detect_feet_arm()` | Определение характерных точек плетизмограмм (foot-точек) |
| `compute_pwv()` | Расчёт PTT, СРПВ и фильтрация выбросов методом MAD |
| `compute_hrv()` | Вычисление метрик ВСР с применением критерия Малика |
| `process_file()` | Главная функция модуля, реализующая полный цикл обработки одного CSV-файла |

Глобальные константы (частота дискретизации, число каналов, пороги и т.п.) задаются в начале файла.

## 2. batch_pwv.py

**Назначение:** пакетная обработка всех пациентов из `config.json`. Формирует выходные таблицы и интерактивный дашборд.

### Основные функции

| Функция | Описание |
|---------|----------|
| `run_batch()` | Последовательная обработка всех файлов, формирование четырёх выходных таблиц |
| `extract_features()` | Построение расширенного вектора признаков, вычисление флага качества `quality_ok` |
| `patient_summary()` | Агрегирование показателей по пациенту с взвешиванием по числу валидных пар |
| `plot_patient_comparison()` | Шестипанельный интерактивный дашборд сравнения пациентов |

## 3. pwv_cnn.py

**Назначение:** 1D свёрточная нейронная сеть для оценки PTT из сырых трёхканальных сигналов.

### Особенности
- **Обучение:** self-supervised — метки PTT берутся из алгоритмического пайплайна (`pwv_single`).
- **Архитектура:** 4 свёрточных блока + global average pooling + регрессионная голова.
- **Функция потерь:** Huber (устойчива к выбросам).
- **Оптимизатор:** Adam с изменением learning rate по правилу `ReduceLROnPlateau` (lr от 10⁻³ до 10⁻⁵).

### Основные функции

| Функция | Описание |
|---------|----------|
| `build_dataset()` | Извлечение обучающих примеров из CSV-файлов в виде трёхканальных временных окон |
| `build_cnn()` | Построение архитектуры 1D CNN |
| `train_cnn()` | Обучение модели со стратегией leave-one-patient-out, ранней остановкой и снижением lr при плато |
| `evaluate_cnn()` | Вычисление MAE, RMSE, R² и построение scatter-графика |
| `run_inference()` | Применение алгоритмического и CNN-методов к одному файлу с отображением сравнительного четырёхпанельного графика |
| `run_inference_batch()` | Последовательный инференс по всем файлам из `config.json` |

Интерпретация `agreement_ms` (разность оценок алгоритма и CNN):
- **< 20 мс** — методы согласованы, сигнал качественный;
- **20–40 мс** — умеренное расхождение;
- **> 40 мс** — возможен артефакт или слабый контакт датчика.

## 4. pwv_bp_calibration.py

**Назначение:** индивидуальная настройка линейной зависимости «СРПВ – АД» и оценка артериального давления по новым значениям СРПВ.

### Математическая модель
Линейная зависимость:
BP = a · PWV + b

Коэффициенты `a` и `b` определяются методом наименьших квадратов по парным измерениям. Калибровка строится отдельно для систолического (СД), диастолического (ДД) и среднего (MAP) давления. Среднее артериальное давление рассчитывается как:
MAP = ДД + (СД - ДД) / 3


### Основные функции

| Функция | Описание |
|---------|----------|
| `extract_pwv_from_files()` | Автоматическое извлечение СРПВ из списка CSV-файлов |
| `run_calibration()` | Построение линейной регрессии МНК, вычисление метрик качества (r, R², MAE), отображение настроечных кривых |
| `estimate_bp()` | Оценка СД, ДД и MAP по новым значениям СРПВ с проверкой физиологических границ |
| `estimate_bp_from_files()` | Полный цикл: новые CSV-файлы → СРПВ → оценка АД |

Требования к калибровке:
- Минимальное число точек — **3** (рекомендуется **от 5**).
- Коэффициенты индивидуальны и не переносятся между пациентами.
- Надёжная оценка только в пределах диапазона СРПВ, покрытого калибровкой.
- R² порядка 0,5 означает, что ~50% вариабельности АД не объясняется СРПВ (влияют тонус сосудов, эмоциональное состояние и др.).
